## About

**Tag Party** is a multiplayer party-style custom game where one player is selected as **IT** and must chase the others.

Tag another player and the role immediately transfers to them.

> Don't be IT when it matters.

The project aims to turn the familiar movement, heroes, and abilities of Dota 2 into a short, fast-paced, and chaotic multiplayer experience.

- One player is randomly selected as **IT**
- IT receives a movement advantage
- Getting close enough to another player transfers the role
- A short cooldown prevents instant tag-backs
- Arenas will feature different routes, hazards, and interactive elements
- Future modes will introduce different rules and variations of Tag

The core rules are intentionally simple, while maps, heroes, and game modifiers provide the depth.

## Planned Features

<p>
  <img src="https://img.shields.io/badge/Roadmap-Active-2ecc71?style=flat-square" alt="Active Roadmap">
  <img src="https://img.shields.io/badge/Arenas-Planned-3498db?style=flat-square" alt="Custom Arenas">

  <img src="https://img.shields.io/badge/Game%20Modes-More%20Coming-e67e22?style=flat-square" alt="More Modes">

Tag Party is being designed around a simple core rule, with most of the variety coming from arenas, movement options, hazards, and different ways to play Tag.

Planned additions include:

- Multiple custom arenas with distinct layouts and play styles
- Interactive map elements such as teleporters, jump pads, doors, and shortcuts
- Traps and environmental hazards
- Temporary power-ups and movement abilities
- Dynamic round modifiers
- Multiple Tag variants and alternative rule sets
- Custom HUD, timers, scoreboard, and round feedback
- Improved particles, sound effects, and visual feedback
- Spectator-friendly presentation
- Public multiplayer through Dota 2 Arcade

The goal is to keep the base game immediately understandable while adding enough variety for matches to remain unpredictable and replayable.

The project is currently in early development, with the initial focus on making the core Tag loop reliable and fun before expanding into additional maps and features.

The game is built using:

- **Dota 2 Workshop Tools**
- **Source 2**
- **Lua / VScript**
- **Hammer**
- **Panorama**

The codebase is being kept modular so gameplay systems such as tagging, rounds, scoring, player state, map events, and future game variants can evolve independently.

Development is currently focused on local multiplayer testing, bot-based iteration, and validating the basic movement and Tag mechanics before moving into presentation and content.

Contributions are welcome.

Tag Party is intended to remain an open project where developers, map makers, designers, and players can help shape the game as it grows.

You can contribute by:

- Reporting bugs or unexpected gameplay behavior
- Suggesting arenas, mechanics, power-ups, or game variants
- Improving Lua/VScript gameplay code
- Creating or improving Hammer maps
- Working on Panorama UI
- Improving particles, sounds, or presentation
- Testing multiplayer builds and providing feedback
- Submitting pull requests for existing issues or improvements

If you are unsure where to start, opening an issue with an idea or question is completely fine.
