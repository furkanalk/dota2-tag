# Tag Party Licensing

Tag Party uses a split licensing model so the game can remain open to community
contributions while the official project identity and production services remain
under the control of the project owner.

## Open-source game code

Unless a file or directory explicitly states otherwise, the software source code
in this repository is licensed under the **GNU General Public License v3.0 only
(GPL-3.0-only)**. The full license text is available in [LICENSE](LICENSE).

This includes the game logic, scripts, UI source, repository tooling, and other
software source files committed to this repository.

Copies received under GPL-3.0-only keep the rights granted by that license. An
alternative license offered by a copyright holder does not revoke GPL rights
already granted for an existing GPL copy.

## Alternative licensing

The copyright holder may also offer the code they own under a separate commercial
or proprietary license.

This allows the public project to remain GPL-licensed while preserving the option
for future platform, publishing, distribution, or commercial partnerships.

Code contributed by third parties may be included in alternative licensing only
when the project has the necessary rights to do so. For that reason, pull-request
contributions are subject to the [Contributor License Agreement](CLA.md).

## Tag Party name and branding

The GPL software license does **not** grant permission to present a fork,
derivative project, service, or Workshop item as the official Tag Party project.

Unless explicitly licensed otherwise, original Tag Party branding is reserved,
including:

- the Tag Party name when used to identify the official game or service;
- the Tag Party logo;
- original key art and promotional artwork;
- official visual identity and branding assets.

You may accurately describe a derivative project as being "based on Tag Party" or
"forked from Tag Party", provided that the description does not imply official
status, sponsorship, or endorsement.

This document does not claim that any Tag Party mark is registered. Trademark
rights, where applicable, are separate from the GPL copyright license.

## Original non-code assets

Original artwork, music, sound, logos, promotional media, and other non-code
assets are **not automatically licensed under the GPL merely because they are
stored in or referenced by this repository**.

When original non-code assets are added to the repository, their directory or
file should contain an explicit license notice. If no open license is stated for
an original Tag Party branding or promotional asset, it should be treated as
all rights reserved by its copyright holder.

Game-source assets that are intentionally distributed under GPL should be marked
accordingly.

## Valve and third-party content

Dota 2, Source 2, Dota heroes, Valve trademarks, and Valve-owned assets remain
the property of Valve Corporation and their respective rights holders.

Tag Party cannot grant rights to third-party material that it does not own.

Contributors must not commit extracted paid cosmetics, proprietary third-party
assets, or other material for which they do not have the necessary rights.

## Backend and production services

The official Tag Party production backend, player database, ranked systems,
anti-abuse systems, secrets, credentials, operational infrastructure, and other
live-service components are not part of this repository unless explicitly
added in the future.

Those components may be maintained privately and under separate terms.

To avoid licensing ambiguity, proprietary backend source should live in a
separate private repository rather than inside this GPL-licensed game repository.

## Contributions

Community contributions are welcome.

By submitting a pull request containing a contribution, contributors must agree
to the [Contributor License Agreement](CLA.md). Contributors retain ownership
of their original work while granting the project the rights described in that
agreement.

The CLA exists to preserve the project's ability to maintain the GPL release and
also offer alternative licenses in the future without having to locate every
past contributor for each licensing decision.

## Pre-release review

Before the first serious public Workshop release, the maintainers should review:

- this licensing split;
- the GPL version choice;
- contributor agreement wording;
- branding and trademark strategy;
- licenses for every original visual/audio asset;
- third-party attribution;
- backend separation;
- any potential Valve or commercial partnership requirements.

This repository policy is an engineering and project-governance setup, not a
substitute for jurisdiction-specific legal advice.
